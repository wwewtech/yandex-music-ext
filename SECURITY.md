# Политика безопасности (Security Policy)

## Поддерживаемые версии

| Версия | Поддержка безопасности |
| :--- | :--- |
| 1.1.x | :white_check_mark: Активно поддерживается |
| 1.0.x | :x: Устарела |

## Сообщение об уязвимости

Если вы обнаружили уязвимость в безопасности расширения, пожалуйста, **не создавайте публичный Issue**.

Вместо этого:
1. Воспользуйтесь разделом [GitHub Security Advisories](https://github.com/wwewtech/yandex-music-ext/security/advisories/new).
2. Либо свяжитесь с мейнтейнером напрямую.

Мы проверим отчет и подготовим патч в кратчайшие сроки.
